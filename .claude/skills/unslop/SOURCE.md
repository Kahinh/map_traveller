Skill « unslop » de Damir Sokolovsky (@heydamir), licence CC BY 4.0.

- Source : https://github.com/heydamir/unslop, dossier `skills/unslop`, commit `620163eedb` (15 novembre 2026).
- Copié tel quel : `SKILL.md`, `references/*.md`, `scripts/*.mjs`. Aucune modification.
- Non copié : les images de `references/refs/` (1,3 Mo). Les consulter dans le dépôt d'origine avant la passe « Visuals ».
- Les scripts demandent Playwright et ffmpeg, qui ne sont pas installés dans ce projet : ils ne sont pas utilisés ici.

Le crédit ci-dessus doit rester dans toute copie ou adaptation.

Usage dans Map Traveller : **la palette violette s'impose**. Fond, surfaces, barre de titre (`--mt-titlebar`) et accent jaune-vert sont une décision de l'auteur (`ui-da-pnj` § Fondations, `src/styles/tokens.css`) : la règle du skill « surfaces neutres pour une application », comme toute recommandation de changer de teinte ou d'assombrir le fond, ne s'applique pas ici, même en mode « Light slop ». Le reste du skill (espacement, icônes, textes, typographie, détails, mouvement) s'applique, dans les règles de `ui-da-pnj`. Une refonte dans une autre direction a déjà été lancée puis jetée (`docs/agent-notes.md`, 16/11/2026).
